# Contracts（接口契约）

本目录用于支撑 **线A（Django 控制平面）** 与 **线B（Flutter 客户端/节点）** 的并行开发与解耦联调。

## 文件说明
- `openapi.yaml`：REST API 契约（推荐作为后端实现与前端对接的唯一“真相源”）
- `ws-schema.md`：WebSocket 消息契约（type/data 包络、消息方向、字段含义、幂等与错误码建议）

## 变更规则（建议）
1) **兼容优先**：只增不改；新增字段必须向后兼容（可选/默认值）
2) **破坏性变更必须版本化**：例如新增 `/api/v2` 或在消息 `type` 上加版本后缀
3) **示例先行**：每次新增接口/消息，先补示例与状态机说明，再进入实现

## 计费单位说明（重要）
- minute/hour/day/week：按秒数取整（不足 1 单位按 1 单位）
- month：按**自然月（账务时区）**计算；建议采用半开区间 `[started_at, ended_at)` 并以 “end - ε” 取 `YearMonth` 来避免整月双计
